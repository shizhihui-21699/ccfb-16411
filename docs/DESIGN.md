# TSTV 控制字分享对抗与追踪系统 — 设计说明

> 目标读者：本仓库的评审者、以及要在真实现网落地的系统工程师。
> 本文先把**物理约束**讲透，再给架构。因为这类系统 90% 的错误来自
> "想当然地以为可以给每台盒子不同的控制字"。

---

## 1. 问题与威胁模型

攻击者购买**一张**合法授权卡（连同其机顶盒），从卡里得到解扰用的控制字
（Control Word, CW），通过互联网把 CW 实时转发给成千上万台盗版机顶盒。
盗版盒子不做授权、不持有卡，只拿 CW 解扰视频。

我方约束（来自现网，不可协商）：

| 约束 | 含义 |
|---|---|
| **零卡顿** | 直播节目在合法用户侧不允许出现任何可感知的卡顿/马赛克。 |
| **老盒子不可换** | 全网数百万台存量机顶盒/卡，固件不能升级，协议不能改。 |
| **广播带宽极小** | 授权/密钥信息走广播通道，可用带宽只有几十 kbit/s 量级，且要服务全网。 |
| **CW 全网唯一** | 见 §2.1，同一路视频流的 CW 对所有盒必须相同。 |

---

## 2. 约束分析：为什么"给每台盒子发不同控制字"不可行

这是整个设计的基石，必须一开始就排除错误方向。

### 2.1 控制字全网唯一

加扰发生在**播出端一次**：一路视频流用 `CW_t` 加扰后广播出去，所有接收端
拿到的**是同一段密文**。解密要求所有盒子用**同一个** `CW_t`。如果给甲盒发
`CW_t^A`、乙盒发 `CW_t^B`，那么甲乙解出的画面必然不同，而实际密文只有一份
——物理上不可能。所以：

> **CW 的"值"不能有意区分。**任何"每卡一 CW"的方案在数学上就不成立。

推论：可被"差异化"的只有**与 CW 值无关的侧面**：

1. **下发通道/分组**（哪张卡从哪个 PID/时隙收到 ECM）；
2. **老盒子忽略的保留字段**（协议里已定义但固件跳过的位）；
3. **下发时刻**（在一个合法预取窗口内，不同分组在不同时间收到同一 CW）。

本设计把差异化**全部**放在这三处 → 对画面内容零影响 → 从构造上保证零卡顿。

### 2.2 盒子不可换

存量盒子只认现有 ECM/EMM 段结构和现有卡命令集。因此：

- 不能引入新段类型、新握手、新固件特性；
- 差异化只能借用**已有**机制：分组（band）、每卡 EMM（本来就为点播/授权而存在）、
  回传信道（本来就为 PPV 回执而存在）。

### 2.3 带宽小

ECM 要覆盖全网、且要**前瞻下发**（§3.1），ECM 的重复率直接吃带宽。
每卡 EMM 是 O(N)，**不能**常态广播，只能按需、对**小范围**卡片下发。
这决定了追踪必须用**分组测试**（group testing），把 O(N) 的逐卡探测压成
O(log N) 轮、每轮只覆盖一小撮卡（§5）。

## 3. 架构：三层防御

三层各自负责不同的失败模式，互不依赖。

### 3.1 第一层：CW 快速轮换 + 前瞻广播（压制盗版服务质量）

**机制**：CW 周期 `P` 缩短到 0.5–2 s；广播 ECM 携带**前瞻窗口**
`[now, now+L]`（`L` 覆盖若干周期，例如 3–5 s），且每个 ECM 在窗口内**重复
R 次**并跨多个载波冗余。

**合法用户为何零卡顿**：盒子在本地缓存未来 `L` 内所有周期的 CW，到周期边界
按**本地时钟**切换。只要缓存里始终有未来周期的 CW，广播抖动、单包丢失都不
影响播放——`L` 秒的缓冲 = `L`/`P` 个周期的余量。

**对盗版的伤害**：盗版盒不持卡，无法解 ECM，只能等合法盒把明文 CW 转出来。
转发链路引入延迟 `D`（编码 + 网络 RTT + 盗版服务端重分发）。盗版盒拿到
`CW_t` 的时刻是 `(合法盒可用时刻) + D`。当 `D` 随时间抖动、且 `P` 很短时，
盗版服务会**周期性错过周期边界**——画面出现规律性马赛克/黑帧。
注意：这一层**不保证每周期都失败**（那会伤及合法侧的余量），它是**服务质量
劣化**武器，把盗版服务的"可看性"打到不可接受，逼用户离开。

> 零卡顿是**合法侧**的硬保证（靠缓冲构造性成立）；第一层的目标是让**盗版侧**
> 抖动，两者用不同参数、不同链路，互不冲突。

### 3.2 第二层：分组测试定位（找出是哪张卡）

全网卡按 `K` 个**分组（band）**划分。每个分组有自己的 ECM 载波/时隙
（共享同一 CW 值，只在下发通道上区分）。`K` 受带宽预算约束（§6）：广播侧
最多能同时承载 `K` 个变体流。

**先纠正一个常见但错误的方案**：直觉上会想"把某个候选子集 S 重新加密（rekey），
让 S 里的卡拿不到未来 CW；若盗版随之失效，则分享卡在 S 内"。**这个方案在物理上
不成立**：分享卡本身就是一张**合法卡**，rekey 后它会通过广播 EMM 正常拿到新密钥，
继续解出 CW 继续转发——它不会"失明"。任何基于"让分享卡解不出自己 ECM"的探测，
必然同时让**同组所有合法卡**解不出（它们收到同一 ECM，不可区分），等于惩罚无辜。

真正可部署的探测只有下面两类，**代价不同、都必须如实标注**：

#### A. 下发时刻指纹（零干扰，定位到组）

每个 band 的 ECM 在周期内使用**互不相同的微小偏移** δ_b 下发（都在合法盒前瞻
窗口内，不影响播放）。盗版服务把 CW 转发出去时，**逐周期可用性的边沿时刻**会
带上 δ_b 的指纹（这是统计分析，不是内容差异）。运营侧对盗版流做**逐周期可用性
时间序**观测，用相关/最大似然反推 band。**零卡顿、零干扰**，但一次只能把范围
缩到"某个 band（≈N/K 张卡）"，且需要较多观测周期、对抖动敏感。

#### B. 短暂停发（有界干扰，组内定位到卡）

在已由 A 锁定、或嫌疑已很小的**单个 band** 内，对子集 `S` **短暂停发**其 ECM
超过前瞻窗口长（`> L` 个周期）。该子集的**合法盒会在此期间卡顿**——这是**真实
代价**，必须计入并最小化：(i) 只在单个 band 内做，受影响面 ≤ N/K；(ii) 停发时长
仅略超 `L`；(iii) 掉线可被合法盒察觉，因此把"停发"设计成**短促且低频**，并在
运营商可接受的服务等级内。

- 若盗版在停发窗口后**失效** → 分享卡在 `S` 内（它的 CW 断了）；
- 若盗版**继续** → 分享卡在 `S` 外（它的 CW 仍从别的卡/通道流出）。

一次给出 1 bit。对 `K` 个分组二分需 `O(log K)` 轮；锁定组内 `≈N/K` 张卡后，
在该组内递归二分需 `O(log(N/K))` 轮，合计 `O(log N)` 轮。**每轮广播开销只覆盖
被探测子集的通道**，不随 N 线性增长。

> **诚实边界**：方案 A 零卡顿但只能到组；方案 B 能到卡但有**局部、有界、可计量**
> 的合法卡顿。本仿真对二者都建模：`run_trace` 走 B（并统计受影响合法盒的卡顿），
> `fingerprint` 的思路与 A 同源（用可观测的符号而非停发来区分子集）。§4 的
> "零卡顿"结论仅对**方案 A 与稳态广播**成立；方案 B 的卡顿是显式列出的已知代价。

### 3.3 第三层：每卡差异化授权 + 回执（标识与反克隆）

每张卡的 EMM 用**该卡自己的长期密钥** `K_card` 认证并加密（`K_card` 由主密钥
对卡号派生）。EMM 携带：

- `epoch`（本次授权期号，单调递增）；
- 该卡**所属分组**与本次**探测号** `probe_id`；
- 卡的撤销位。

于是"授权信息"天然逐卡不同：即便广播，也只有目标卡能验证/接受（tag 用
`K_card`）。这既是**可追溯的差异化信息**（卡的 `(分组, probe_id, epoch)` 组合
构成指纹），又是**单卡撤销**能力。

回传信道（老卡本来就有的 PPV 回执）每 `epoch` 上报
`ack = HMAC(K_card, "ack"‖epoch)`。两个作用：

1. **存活/静默检测**：被用于喂盗版服务的卡若行为异常（如全天候高频 ECM 使用
   而回执稀疏），进入嫌疑名单；
2. **反克隆**：若卡被克隆到两台盒子，两盒会发出**相同 `ack` 但不同来源标识**
   → 立即判为克隆卡。

> **安全假设（明确写出）**：本设计假设攻击者能**导出明文 CW**（这正是威胁
> 模型），但**不能提取 `K_card`**。若攻击者能读出 `K_card`，则任何基于卡的
> 方案都失效——那是安全芯片的物理攻击，属于另一层防线（见 §8）。

## 4. 零卡顿保证（构造性论证，及它的边界）

合法播放路径：`收到 ECM → 校验 CRC/tag → 用分组密钥解出 CW → 按 (program, period) 存入缓存 → 周期边界按本地时钟取用`。

对**稳态广播**与**方案 A（时刻指纹）**，零卡顿由构造保证：

- **缓存深度**：广播保证任意时刻缓存中含未来 `L/P ≥ 2` 个周期的 CW。
  单次 ECM 丢失/延迟只要 `< L` 就无影响；配合 `R` 次重复（每份独立丢失，
  仅当全部副本丢失该 ECM 才失效），抗突发丢包。
- **前瞻重发**：真实头端每周期**重发整个前瞻窗口**，故一个窗口内某 ECM 丢了，
  下一周期还会再发——这是"单包丢失不致卡顿"的真正来源。
- **切换原子性**：盒子以 `period` 为唯一时间基准，`CW_{t+1}` 在 `t+1` 起始
  生效，不存在"新旧并用"空档。
- **无状态**：解出的 CW 只依赖 `(program, period)`，headend 可确定性重发任一周期的
  ECM，补发不引入额外状态。

**边界（不隐藏）**：

- **方案 B 的短暂停发会被合法盒察觉**。它的卡顿是显式代价，仅在已锁定的单 band
  内、短促发生，本仿真逐次统计（`TraceReport.affected_legit_glitches`）。
- 前瞻 `L` 越深，合法侧越稳，但也**给盗版转发更多时间**（§3.1 的张力）。`L`、`P`
  需按现网抖动与盗版延迟分布调参，本仓库 `sweep` 给出该权衡曲线。
- 0.2% 丢包下默认参数合法卡顿恒为 0（`tests::legit_never_glitches` 与 CLI 实测）；
  丢包升到 30% 这类极端时，`L=2` 会破、`L=4` 仍稳（`shallow_lookahead...` 测试）。

## 5. 追踪算法细节

### 5.1 分组测试控制器

```
# 阶段 A（零干扰，可选）：用下发时刻指纹把嫌疑缩到单个/少数 band
suspects = fingerprint_narrow(all_bands)      # 或从全部 band 开始

# 阶段 B（有界干扰）：在嫌疑 band 内用短暂停发二分到卡
while |suspects| > 1 and rounds < budget:
    S = choose half of suspects
    suspend_ecm(S) for L+1 periods             # 该子集合法盒短促卡顿（已计入）
    if piracy_broken(observation_window): suspects = S
    else:                                 suspects = suspects \ S
```

- `fingerprint_narrow`（阶段 A）在**本仓库中未实现**：它需要把各 band 的下发偏移
  δ_b 与中转延迟解耦，存在真实的观测混淆。仿真把它的**输出**（估计 band）作为输入
  代入，并在 `TraceReport` 中标注为外部输入。阶段 B 则**逐位真实仿真**，含其卡顿代价。
- `piracy_broken` 是运营侧观测（盗版流可用性/投诉/主动探针）的**外部 oracle**；
  仿真里阶段 B 由真实机制提供：对某子集停发后，检查**盗版盒**是否在该 band 上断流。
- 每轮开销 = 被探子集的 ECM 停发 + 子集卡的 EMM，二者都正比于 `|S|`，
  单轮 ≤ 广播预算。
- **停发只针对盗版依赖的通道**：因为我们已知分享卡在嫌疑 band 内（阶段 A）或已二分
  到小集合，停发面被压到最小。

### 5.2 合谋抗性：指纹码

若多张卡合谋分享，需要**指纹码**：给每张卡分配一个码字（体现在 `(分组,
子通道, probe 应答模式)` 上），任意 `≤c` 张卡的合谋无法伪造出一个不属于
其成员集合的码字，且追踪器能至少指认一名成员。

本仓库实现一个 **q 元分组指纹码 + 经验解码器**（`tstv-trace::fingerprint`）：
码长 `m`、字母表大小 `q`、合谋上限 `c`。构造采用"随机 + 列去偏"，解码用
"每个成员累计其在各列出现于合谋码字中的一致性得分，取最高分"。
测试在 `c ≤ 3`、`N ≤ 4096` 上验证**至少指认一名真实合谋者**且**误伤率低**。
这是工程可用的近似 Tardos，而非可证界的 Tardos——文档明确标注。

> 说明：分组测试（§5.1）解决**单卡**分享（最常见），指纹码（§5.2）解决
> **小规模合谋**。两者组合：先分组测试缩到小集合，再在该集合上启用指纹码。

### 5.3 反克隆

回传 `ack` 携带 `(card_id, epoch, ack_tag, source_id)`。`source_id` 是回传
链路可得的设备/网络标识（老卡回执里已有）。同一 `ack_tag` 在**不同 `source_id`**
出现 → 克隆。仿真 `tests::clone_detected` 覆盖。

## 6. 带宽预算

设 ECM 段 `B_ecm` 字节、重复 `R`、前瞻 `L`、周期 `P`，分组数 `K`，
目标 ECM 通道 `C` bit/s：

```
每秒 ECM 字节 ≈ K · (1000/P) · R · B_ecm        （每个新周期每组发 R 次）
```

例：`B_ecm=64 B`、`P=1000 ms`、`R=3`、`K=64` → `64·1·3·64 = 12 288 B/s ≈ 98 kbit/s`。
在几十–百 kbit/s 量级可行。**这是 K 的上限来源**：`K` 越大，定位越快，
但带宽越紧。`tstv-cas::bandwidth` 给出精确核算，CLI 打印每个场景的占用。

EMM 常态不广播；探测期只对子集 `|S|` 发，`|S|·B_emm` 字节/轮，受同一预算约束，
控制器会**节流**（§7 `RekeyBudget`）。

## 7. 模块划分

| crate | 职责 |
|---|---|
| `tstv-core` | 确定性密码（AES-128/CMAC/HMAC-SHA256/KDF/CTR）、CRC-32、线路格式（严格解码）、类型、时间窗口、确定性 RNG |
| `tstv-cas` | headend（ECM/EMM 生成、分组管理、探测/停发调度、带宽核算）、卡（EMM 校验、ECM 解密、CW 缓存、ack）、盒（播放仿真、卡顿统计） |
| `tstv-trace` | 分组测试控制器、q 元指纹码与解码器、克隆检测 |
| `tstvd` | 端到端仿真二进制 + CLI + 场景与指标报告 |

## 8. 局限与不做的事（诚实边界）

- **不实现真加密视频**：仿真用"周期边界是否持有所需 CW"建模卡顿，这是
  加扰系统的忠实抽象（缺 CW 即无法解该 GOP）。
- **指纹码非 Tardos 可证界**：经验验证，不宣称信息论最优。大规模合谋
  （`c` 很大）需要更强码与更长码字，属后续工作。
- **不防 `K_card` 物理提取**：见 §3.3 假设。真实现网靠安全芯片 + 白盒，
  不在本仓库范围。
- **第一层只压制不消灭**：短周期 + 前瞻是对盗版**服务质量**的持续压制，
  最终定位靠第二、三层。参数需按现网 `D` 分布调优。
- **`source_id` 依赖回传**：无回传的纯广播卡只能靠第二层定位，不能做克隆检测。

## 9. 仿真指标（`tstvd` 输出）

- `legit_glitches`：合法侧卡顿次数（目标恒为 0）。
- `pirate_glitch_rate`：盗版侧周期失效率（第一层效果）。
- `identify_rounds` / `identify_bandwidth`：**卡定位阶段**所需轮数与广播字节
  （band 定位阶段由外部时刻指纹子系统提供，仿真中以真值代入，见 §3.2A）。
- `affected_legit_glitches`：**卡定位阶段**停发引起的合法盒·周期卡顿，即追踪到单卡的真实、有界代价。
- `false_positive`：追踪误伤率。
- `clone_detected_at`：克隆检测延迟（epoch 数）。
- `ecm_bitrate`：ECM 通道占用，对照预算。
